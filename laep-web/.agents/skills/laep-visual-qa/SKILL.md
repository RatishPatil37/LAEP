
# LAEP Visual QA Skill

## Purpose

Evaluate the actual rendered LAEP application rather than judging only source code.

## Inspect

Check:

- visual hierarchy
- typography
- spacing
- alignment
- navigation
- responsiveness
- animations
- 3D composition
- loading states
- errors
- interaction feedback
- scientific readability
- performance

## Look For

Identify:

- generic AI aesthetics
- unnecessary cards
- excessive glassmorphism
- excessive glow
- weak typography
- inconsistent spacing
- visual clutter
- poor mobile layouts
- excessive animation
- broken interactions
- console errors
- poor 3D camera composition
- slow loading
- oversized assets

## Process

1. Start the application.
2. Inspect the desktop experience.
3. Inspect mobile dimensions.
4. Test primary interactions.
5. Check browser console.
6. Identify highest-impact problems.
7. Fix them.
8. Re-test.

## Priority

Fix problems in this order:

1. broken functionality
2. layout problems
3. poor hierarchy
4. performance
5. responsiveness
6. interaction quality
7. animation
8. micro-polish

Do not waste time polishing minor details while major structural problems remain.
