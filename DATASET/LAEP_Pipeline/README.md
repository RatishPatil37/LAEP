# LAEP_Pipeline

- All the values except the CPR are original, extracted from dataset.
- CPR feature is hardcoded
- And the last column "Hazard Class label" is calculated
- The F2_Custom dataset was created using the different .csv files found in the TMC-2, OHRC and DFSAR dataset on ISRO's Pradan website and merged using the python program in generate_custom_dataset.csv using the common parameters such as latitude and longitude.
